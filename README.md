# Nonsense Arcade

Small browser games about things that should not be games: a moon that needs to stay moist,
a bureau that files the weather, a dragon doing its tax return. Every game is a single HTML
file with no build step, no tracking and no account. Most play in English and French.

**Play:** https://lessive-irc.github.io/nonsense-arcade/

qu'il faut garder humide, un bureau qui classe la météo, un dragon qui remplit sa déclaration
